# 使用說明

## 沙盒和模式

兩個分開的設定：**沙盒**管碰得到哪裡（指令有沒有被關住、工具能讀能改的範圍），**模式**管要不要先問你。
預設沙盒開著、一般模式：改檔先秀 diff 問你，白名單的指令直接跑，其他的問。大部分的人不用改；照你的情況該怎麼設，見 [setup-guide.md](setup-guide.md)。

| | 沙盒 | 模式 |
|---|---|---|
| 管什麼 | 碰得到哪裡：指令有沒有被關住、工具能讀能改的範圍 | 要不要先問你 |
| 選項 | 開、關 | 唯讀、計劃、一般、自動改檔、全自動、全部不問 |
| 預設 | 開 | 一般 |
| 開 xj 時 | 設定檔 `sandbox.enabled`；指令列 `--no-sandbox`、`--sandbox` | 設定檔 `defaultMode`；指令列 `--auto`、`--dangerously-skip-permissions` |
| 在 xj 裡換 | `/sandbox off`、`/sandbox on`、點右邊那一欄 | Shift-Tab、`/mode`、點右邊那一欄 |
| 換的時候確認 | 關：按 `y`（Enter 不算，詢問講為什麼） | 全部不問：每次開 xj 第一次進去時打「我了解風險」 |
| 要設定檔先允許 | 不用 | 在 xj 裡切到全自動（`allowFullAuto`）、全部不問（`allowBypass`）。啟動時加 `--auto`、`--dangerously-skip-permissions`，或寫了 `defaultMode: "full-auto"` 的，那次就算允許 |
| 狀態列 | 「沙盒開」「沙盒關（設定檔）」 | 「一般模式」「全部不問模式」… |
| 換不了的 | 模型（只能提議改設定檔，你答應才寫，見下面「改設定」）、專案資料夾裡的檔案 | 同左 |

兩個都放到最寬（全部不問、沒有沙盒）時，狀態列整列標紅。

**沙盒開著**（範圍＝工作目錄和加進來的資料夾）：

| 模式 | 改檔 | 白名單的指令 | 其他指令 | 危險的指令 | 新的網域 | 沙盒外的指令 |
|---|---|---|---|---|---|---|
| 唯讀、計劃 | 不准 | 唯讀的直接跑 | 不准 | 不准 | 問 | 不准 |
| 一般 | 先秀 diff 再問 | 直接跑 | 問 | 問 | 問 | 問 |
| 自動改檔 | 不問 | 直接跑 | 問 | 問 | 問 | 問 |
| 全自動 | 不問 | 直接跑 | 不問 | 問 | 問 | 問 |
| 全部不問 | 不問 | 直接跑 | 不問 | 不問＊ | 擋下 | 不問（內建的擋下＊＊） |

- 範圍外的檔案每個模式都讀不到、改不了（要加範圍：`/add-dir`，見下面「加進來的資料夾」）；家目錄裡範圍外的地方，工具和指令都碰不到（指令讀得到 `sandbox.toolchainReadable` 列的工具鏈資料夾）。
- 指令都在沙盒裡跑（「不問」的也一樣）：寫得到的只有範圍裡，加上暫存和快取的資料夾。
  MCP server 也在沙盒裡跑（設定檔寫 `sandbox: false` 的除外；Windows 的沙盒跑不了 MCP server，開場會講怎麼辦）。
- 新的網域：`sandbox.allowedDomains` 和這次對話允許過的以外的。沙盒外的指令：設定檔 `excludedCommands` 列的（docker 這類），和內建的 flutter、dart、fvm、安裝程式（winget、scoop、brew）。
- 計劃跟唯讀一樣，最後提出做法，你核准後切到一般模式開始做。
- ＊刪掉重要的地方、你自己加的危險規則、切換成 root 照樣問（見下面「不管沙盒、模式都一樣」）。
- ＊＊列進 `excludedCommands` 的直接在沙盒外跑；內建的 flutter、dart、fvm、安裝程式擋下，畫面講怎麼辦：換到會問你的模式、把它列進 `excludedCommands`，或關掉沙盒。

**沙盒關掉**（沒有範圍）：

| 模式 | 改範圍裡的檔 | 範圍外的檔 | 指令（白名單也不算） | 危險的指令 |
|---|---|---|---|---|
| 唯讀、計劃 | 不准 | 讀：問；改：不准 | 唯讀的問，其他不准 | 不准 |
| 一般 | 先秀 diff 再問 | 問 | 問 | 問 |
| 自動改檔 | 不問 | 問 | 問 | 問 |
| 全自動 | 不問 | 問 | 問 | 問 |
| 全部不問 | 不問 | 不問 | 不問 | 不問＊ |

- 指令以你的權限跑，網路也沒有東西管：所以除了全部不問，每個指令都問。
- 範圍外的檔：讀、改都問（改的先秀 diff、標紅，沒有「改檔都允許」；`/undo` 還原得了）。照樣一律擋的見下面那一張表。
- `web_fetch` 照樣問新的網域（全部不問除外）。沒有沙盒時，全自動跟自動改檔一樣。
- 設定檔沒寫 `sandbox: false` 的 MCP server 不開（全部不問除外：在沙盒外開，以你的權限跑）。
- ＊跟沙盒開著時一樣：刪掉重要的地方、你自己加的危險規則、切換成 root 照樣問。

**不管沙盒、模式都一樣**：

| | |
|---|---|
| 一律擋 | 機密檔（`.env`、金鑰檔…）；受保護的檔案（`.git/hooks`、`.vscode/tasks.json`…）；會被自動執行的地方（shell 的啟動檔、開機和登入時自動跑的、`~/.ssh`、`~/.xing-janus`…）。沙盒關掉時，指令裡只擋得到直接寫出名字的 |
| 全部不問也照樣問 | 切換成 root（`sudo`…）；認不出是不是機密檔的（有好幾個名字的檔案）；刪掉根目錄、根目錄下的第一層、家目錄、工作目錄和它的上層、加進來的資料夾（設定檔可以關掉）；你自己加進 `permissions.danger` 的；xj 看不完的指令（一層包一層包得太深、大括號展開出太多字）；模型提議改設定（`settings_propose`） |
| MCP 的工具 | 問（`autoApprove` 列的不問）；唯讀、計劃只准設定檔標成唯讀的；全部不問不問 |
| 預算上限 | 照樣有效，到了就停下來問（`/budget`） |
| 不信任的資料夾 | 只能用唯讀、計劃 |

- 危險的指令（`rm -rf`、`git push`、`sudo`…）問的時候標紅講原因。內建的有哪些、怎麼增減，全部列在 [config.md](config.md) 的「內建的白名單、危險清單、機密檔」。
- 用 `/mode` 或 Shift-Tab 切換。不信任的資料夾只能用唯讀和計劃模式。設定檔沒開放的全自動、全部不問，Shift-Tab 會跳過（第一次跳過時講怎麼打開），
  `/mode` 不加參數會列出這次切不到的和原因。切換時對話裡會記一行「模式：一般 → 自動改檔」（放寬的用黃色）；
  一般模式下正在打字時按的 Shift-Tab，等你送出那一句才記（不然會弄亂輸入列）。

### 沙盒

指令在作業系統的沙盒裡跑：寫得到的只有工作目錄和也能改的加進來的資料夾（加上暫存和快取的資料夾）、讀不到機密檔和家目錄裡的其他地方、網路只到允許的網域。
沙盒和模式是分開的兩個設定：沙盒管指令碰得到哪裡，模式管要不要先問你。

- **開 xj 時**：照設定檔的 `sandbox.enabled`（預設開）；這次用 `--sandbox`、`--no-sandbox` 蓋過。
- **在 xj 裡換**：`/sandbox off` 關掉、`/sandbox on` 打開、`/sandbox` 看現在的狀態（起不來、沒裝好的話講原因和怎麼辦）；全螢幕模式點右邊那一欄的「沙盒」也一樣。只管這次對話，不改設定檔。
  - **關掉要按 `y`**（Enter 不算，Enter＝是開著也一樣，詢問會講為什麼）。關掉之後指令以你的權限跑、碰得到整台電腦，白名單不生效：
    每個指令都問（全部不問模式除外：關掉之後什麼都不問，詢問會用紅字多講一句）。設成在沙盒裡跑的 MCP server 收掉，之後不開（全部不問模式除外：在沙盒外開）。
  - **工具的範圍跟著沙盒走**：沙盒開著（或起不來）時，讀檔、改檔、搜尋的工具跟沙盒裡的指令同一個範圍（工作目錄和加進來的資料夾），外面的擋下來。
    沙盒關掉時沒有範圍：工作目錄以外的讀先問（唯讀、計劃模式也問）、改檔先秀 diff 再問而且標紅（自動改檔、全自動、「改檔都允許」也一樣問），
    全部不問模式不問；問了改的 `/undo` 還原得了。照樣一律擋：機密檔、放憑證的地方（`~/.ssh`、`~/.aws`、`~/.gitconfig`…）、xj 自己的資料夾，
    改的話另外擋受保護的檔案（任何一層的 `.git`、`.vscode`…）和之後會自動執行的地方（shell 的啟動檔、開機和登入時自動跑的、排程、`/etc`、`~/.gradle/init.d` 這類；Windows 上 PowerShell 的設定檔，「文件」被轉到 OneDrive 的話照實際的位置）。
  - **打開**：開得起來才換，起不來的照舊沒有沙盒、講原因（跟開場一樣；Windows 沒裝好的會講怎麼裝）。這次對話 `/add-dir` 加的資料夾、允許過的網域照樣算；
    MCP server 之後在沙盒裡開。Windows 開沙盒要一陣子（跟開場一樣，大的工具鏈要好幾分鐘，會講做到哪裡）；
    開場沒有沙盒時用的 PowerShell 沙盒的帳號跑不了的話（裝在使用者資料夾的 7），打開之後這次對話改用跑得了的那一個（會講）。
  - 模型在跑的時候不換（跑到一半的指令用的是舊的那一個）：等這一輪做完。背景還有指令在跑的話先問你，停掉再換（見下面「指令的時間上限、背景跑」）。模式不變。
  - 換了之後對話裡記一行（「沙盒：開 → 關（/sandbox）」），狀態列、右邊那一欄寫是哪裡關的（`--no-sandbox` 是「指令列」、設定檔、`/sandbox`），模型也會知道。
  - 模型換不了沙盒：只有你打的 `/sandbox`、點的右邊那一欄、設定檔、指令列換得了（專案資料夾裡的檔案也不行）。
    模型只能提議改設定檔的 `sandbox.enabled`：要你按 `y` 才寫，下次開 xj 起才算（見下面「改設定」）。

### 全自動模式

設定檔寫 `"allowFullAuto": true`，之後 Shift-Tab、`/mode` 就切得到它；或這次啟動時加 `xj --auto`（設定檔的 `defaultMode` 設成 `"full-auto"` 也算）。改檔和沙盒裡的指令都不會先問你，
由沙盒當安全邊界。只能在**信任的資料夾**用。沙盒和模式是分開的兩個設定：沒有沙盒（`--no-sandbox`、`/sandbox off`、Windows 還沒裝沙盒）、或沙盒有一部分擋不到
（Windows 的專案太大、機密檔沒找完；沙盒的帳號寫得進 PATH 上的資料夾這類沙盒外會被執行的地方）的時候也進得去，但只有改檔不問，**指令每個都問**（開場會講）。

還是會問：危險清單上的指令、連新的網域、在沙盒外跑的指令（`excludedCommands`、flutter 這類沙盒裡跑不了的工具）、不在白名單的 PowerShell 指令（PowerShell 的字串拼得出任何路徑和指令）、MCP 的呼叫，還有認不出是不是機密檔的情況
（例如有多個名字的檔案）。還是一律擋：機密檔、之後會在沙盒外被執行的檔案（`.git/hooks`、`.vscode/tasks.json`…）。預算的上限照樣有效。

沙盒擋不到的事要你自己留意：

- **工作目錄裡的東西**：沙盒本來就讓指令改工作目錄，危險清單以外的刪除、覆寫不會問；指令改的檔案 `/undo` 還原不了。**開始前先 git commit。**
- **你之後在沙盒外跑的東西**：原始碼、`package.json` 的 scripts 本來就是它的工作範圍。**在沙盒外跑 build、`npm start` 之前，先看過 `git diff`。**
- **允許過的網域**：已經允許的網域，沙盒裡的程式送東西過去不會再問。
- **檔案裡藏的指示**：被誘導的話，危險清單以外的事都會直接做。只在你信任的程式碼裡用。

改回信任（`/trust`）之後不會自己回到全自動，要你再切一次。`xj -p` 只有明確加 `--auto` 才用全自動：設定檔的預設模式是全自動或自動改檔的話，`-p` 用一般模式。

### 全部不問模式

`xj --dangerously-skip-permissions` 啟動。改檔、指令（包括危險清單上的）、PowerShell、MCP 的呼叫都不會先問你。
沙盒和模式是分開的兩個設定：全部不問只換模式，沙盒照它自己的設定（設定檔的 `sandbox.enabled`，這次用 `--sandbox`、`--no-sandbox` 蓋過；開了 xj 之後用 `/sandbox` 換）。

- **沙盒開著**：指令照樣關在沙盒裡（MCP server 也是），讀不到機密檔、寫不到工作目錄以外。網路只到允許過的網域（`sandbox.allowedDomains`、這次對話允許過的），
  沒允許過的不問就擋，`web_fetch` 也一樣，要放行就加進 `sandbox.allowedDomains`。`excludedCommands` 列的照樣在沙盒外跑、不問；
  沙盒裡跑不了的工具（flutter、dart、fvm、安裝程式）不問就擋，講要用的話怎麼辦（換到會問你的模式、列進 `excludedCommands`，最後才是關掉沙盒）。
  沙盒擋不住的是工作目錄裡的刪改（指令改的 `/undo` 還原不了）和 push 到允許過的網域：**開始前先 git commit。**
- **沒有沙盒**（`--no-sandbox`、設定檔關掉、`/sandbox off`）：讀檔、改檔的工具也不問就碰得到工作目錄以外（一律擋的照樣擋，見上面「沙盒」）。指令能做你的帳號能做的任何事：刪檔案、讀家目錄裡的 SSH 金鑰和雲端憑證、連任何網站、用 Docker；MCP server 也在沙盒外跑。
  檔案、網頁裡藏的指示（提示注入）可以直接叫它做這些事。**只在可以整個丟掉的環境（容器、虛擬機）裡用，開始前先 git commit。**
  在容器裡沙盒常常起不來（起不來會一律拒絕跑指令）：那台的設定檔寫 `"sandbox": { "enabled": false }`，或啟動時加 `--no-sandbox`。

- **照樣一律擋**：直接寫出名字的機密檔（`cat .env`、讀金鑰檔…）、受保護的檔案（`.git/hooks`、`.vscode/tasks.json`…）。認不出是不是機密檔的（有多個名字的檔案）照樣問。
- **擋不到間接的讀法**：沒有沙盒，xj 只看得到指令的字。`grep -r`、`cat *`、`find -exec cat`、`tar`、PowerShell 的 `Get-ChildItem | Get-Content`、
  或模型自己寫的程式，都讀得到資料夾裡的 `.env`，讀到的會送到模型服務。**機密別放在這個資料夾。**
- **切換成 root 照樣問**：`sudo`、`su`、`doas`、`sudoedit`、`pkexec`、`run0`（包在 `env`、`bash -c` 裡面的也算），PowerShell 的 `-Verb RunAs`、`runas`、`sudo`。
  要讓 `sudo` 不問，在設定檔的 `permissions.dangerRemove` 加 `"sudo"`（一般模式也會跟著不標紅）：危險清單的 `sudo` 這一項包含上面 bash 的六個，`su`、`doas` 這些也一起不問。
  這只管那六個：PowerShell 的 `-Verb RunAs`、`runas`、`sudo` 照樣問。
- **刪掉重要的地方照樣問**：刪除根目錄、根目錄下第一層（`/usr`、`/etc`…；Windows 是 `C:\` 和 `C:\Windows`、`C:\Users` 這類）、家目錄、
  工作目錄和它的上層、加進來的資料夾（`/add-dir`、`permissions.extraReadable`）本身和它們的上層。`rm`、`rmdir`、`find … -delete`、`shred`、PowerShell 的 `Remove-Item` 都算，
  包在 `bash -c`、`env`、`xargs` 裡、`cd` 之後的也看；整層刪掉的萬用字元（`rm -rf *`、`rm -rf ~/*`）、看不出要刪哪裡的（變數、`$( )`、`xargs rm`）也問。
  標紅、要按 `y`；`xj -p` 沒有人回答就是拒絕。照指令的字認：寫成程式去刪（`python -c "…"`）認不出來。
  不想被問：設定檔的 `permissions.bypassAsksCriticalDelete` 寫 `false`（只有全部不問模式看它：其他模式本來就問）。
- **你自己加進 `permissions.danger` 的照樣問**：那是你明確說要問的。內建的危險清單照舊不問。
- **模型提議改設定照樣問**（`settings_propose`，見下面「改設定」）：設定檔管的就是模型能做什麼。
- **用 root 跑的時候開不了**：`sudo xj --dangerously-skip-permissions`、或容器裡預設的 root 都會被擋下來，請改用一般帳號。
  Windows 上「以系統管理員身分執行」的終端機也一樣（問不到是不是的時候當成是）。
  在可以整個丟掉的容器裡、又一定要用 root 的話，設環境變數 `XING_JANUS_ALLOW_ROOT_BYPASS=1` 再開。
- **照樣有效**：預算的上限、每輪工具呼叫次數的上限。
- **怎麼進去**：這次啟動時加 `--dangerously-skip-permissions`；或設定檔寫 `"allowBypass": true`，之後 Shift-Tab、`/mode` 切得到；
  `defaultMode` 也可以寫 `"bypass"`（要 `allowBypass`；開 xj 時就確認，取消的話從一般模式開始）。`xj -p` 只認旗標（設定檔的不算）。
- **每次開 xj 第一次進去都要確認**：印警告和使用提醒，要你自己打「我了解風險」再按 Enter（貼上的不算，Esc 取消）；同一次開 xj 之後切出去再切回來不再問。
- **只能在信任的資料夾用**：不信任的話不進去，從唯讀模式開始（不信任的資料夾只能用唯讀、計劃）。
- 狀態列寫「全部不問模式」；沒有沙盒的話整列標紅（兩個都放到最寬）。Shift-Tab 可以切到別的模式，沙盒維持原狀（沒有沙盒的話，切出去之後每個指令都要問）。
- **Windows：沙盒的帳號寫得進 PATH 上的資料夾時**。開沙盒時發現的話，xj 會用系統管理員權限跑 `icacls` 把它擋掉
  （只擋沙盒的帳號寫入；Windows 會跳 UAC，你按了才會跑；在背景跑，不用等）：
  - 沙盒開著：輸入列出來之前**問你一次**（是／否／永久允許）。選「永久允許」就是設定檔的 `sandbox.autoFixWritable` 寫成 `true`，
    之後發現就不問（`/permissions` 看得到、拿得掉）。按「否」就不擋，同樣的地方之後不再問（開沙盒時照樣講白名單不生效）。
  - 全部不問模式：照上次開沙盒時記下的，**不問就擋**。
  - UAC 按「否」或沒擋成就不再自動跑，改印指令讓你自己跑。`-p` 這種沒有人能回答的只印指令。
  - 記錄在 `~/.xing-janus/acl-fix.json`（沙盒讀寫不到），擋之前會核對那是沙盒帳號現在的 SID。
- `xj -p --dangerously-skip-permissions`：沒有人能打字確認，加了旗標就算同意，警告和使用提醒印到 stderr；不信任的資料夾直接結束（exit 2）。
- 不能跟 `--auto` 一起用。

## 權限詢問

- **改檔**：`y` 套用、`n` 不要、`a` 這次對話的改檔都允許。
- **指令**：`y` 執行、`n` 不要。被拒絕的時候，它會換別的方法，不會重試同一件事。
- **Windows**：bash 用的是 Git Bash（白名單、危險清單跟 macOS、Linux 一樣）；另外有 PowerShell，它的白名單只認很單純的唯讀寫法
  （`Get-ChildItem`、`Get-Content`、`Select-String`…，參數是一般的字或單引號），唯讀、計劃模式也只能跑這些；其他的每個都問。
  沒裝 Windows 的沙盒時，bash、PowerShell 的指令都每個都問。
- **網域**：沙盒裡的指令、`web_fetch`（抓網頁）要連一個沒列過的網域時會問：`o` 允許一次、`s` 這次對話都允許、`p` 永久允許、`n` 拒絕。
  兩邊用同一份清單：`curl` 允許過的網域，抓網頁不再問，反過來也一樣。
- **Enter 就是「是」**：預設開（跟 Claude Code 一樣；設定檔寫 `"enterToApprove": false` 就一律要按 y）。一般的詢問按 Enter 就答應（選項上會寫 `[y/Enter]`），網域的詢問是「允許一次」。
  危險的指令、還沒看完的內容（要先按 `v`）、永久允許的確認、放寬的確認（關沙盒、加成也能改的資料夾、放寬的設定）照樣要按 `y`；詢問剛出現的 0.5 秒內的 Enter 不算。
- **永久允許（`p`）**：寫進設定檔，**所有專案都適用**。按了之後還會再問一次，列出要寫進哪個檔、哪一欄、寫什麼，按 `y` 才寫（`n` 回到原本的問題）。
  有這個選項的：沙盒裡的網域（寫進 `sandbox.allowedDomains`）、單純的指令（寫進白名單 `permissions.allow`，寫的是指令加上子指令，
  例如 `npm test`：之後 `npm test --watch` 也算）、MCP 工具（寫進那個 server 的 `autoApprove`）。
  沒有這個選項的：危險清單上的指令、在沙盒外跑的指令（`excludedCommands`）、有 `&&`、管線、重新導向的指令、光一個 shell 或直譯器（`node`、`python`、`bash`）、
  PowerShell 白名單外的指令、改檔（要的話把預設模式設成自動改檔）。機密檔照舊只能自己改設定檔。指令的永久允許只在沙盒開著、信任的資料夾裡才有（寫進白名單才會直接跑）。
  永久允許的東西用 `/permissions` 看、拿掉：它先講現在的狀態和怎麼換（模式、沙盒、資料夾、信任、改檔都允許），再分組列出你永久允許的（有編號，`/permissions remove <編號>` 拿掉）、
  設定檔改了的（危險清單、機密檔、開 xj 時一起加的資料夾…，只能看）、內建的（白名單整份照用途分組、危險清單、機密檔）。
  全螢幕模式列完接著開選單：↑↓ 選、Enter 看細節，按 `y` 才拿掉，Esc 結束；右邊那一欄點「永久允許」直接開選單（`/permissions menu`）。這裡不能新增。
  其他放寬的設定（關掉沙盒、`allowBypass` 這類）列在 `xj doctor` 的「設定檔放寬的」那一列。
- 真的詢問，標題和要你回答的那一行最前面有 `▍`，左邊的標籤是「xj」。模型的文字、檔案內容印不出這個記號：看起來像詢問、前面卻沒有它的，是模型寫的字，不是 Xing Janus 在問你。

## 加進來的資料夾（/add-dir）

在 A 開 xj，就能讀、改跟 A 有關的 B：`/add-dir ../api`。不用在上層（放所有專案的 workspace）開：那樣整個 workspace 的專案都在範圍裡。

- 打了之後問「也要能改嗎？」：選否就是只能讀（讀、搜尋，不能寫）；要能改得按 `y`（Enter 不算）。
- 只能讀、也能改都一樣：不能是家目錄、它的上層、根目錄，也不能是放憑證的資料夾（`~/.ssh`、`~/.aws`…）、xj 自己的資料夾（`~/.xing-janus`）。
- **也能改的**跟工作目錄同一套規矩：改檔照模式問（一般模式先秀 diff）、`/undo` 還原得了，沙盒裡的指令也寫得到；
  機密檔、受保護的檔案（那個資料夾自己的 `.git/hooks`、`.vscode/tasks.json`…）照樣擋。
  - 要在電腦前面信任過那個資料夾（它的 `package.json` 的 scripts、hooks 之後會被執行，跟在那裡開 xj 一樣）：
    還沒信任過的話照開 xj 時的那一題問（記在同一份 `trusted.json`），不信任就只能讀。
  - xj 在沙盒外跑的程式（git、rg…）、PATH 上的資料夾、xj 自己的程式放在裡面的不行（沙盒裡的指令換得掉它們，下次就在沙盒外以你的權限跑）；只能讀的可以。
  - 加的是工作目錄的上層的話會提醒一句：裡面所有的專案都在範圍裡。
  - 那個資料夾有自己的 `AGENTS.md`、`CLAUDE.md` 的話會講出來，模型要改那裡之前先讀。
- `/add-dir` 不帶參數列出這次對話的資料夾（也能改的、只能讀的；設定檔 `permissions.extraReadable` 的另外列）；
  `/add-dir remove <編號>` 拿掉一個：工具和沙盒馬上碰不到（在沙盒裡開著的 MCP server 重開），之前在那裡改的 `/undo` 照樣還原得了。
- 只算這次對話：`/clear` 之後收回。`/resume` 接續之前的對話時，那時加過的照現在的規矩再加一次（也能改的要信任過，沒信任過的先問）。
- **開 xj 時就加**：`xj --add-dir ../api`（也能改，可以寫好幾個）；每次在這個專案開都要加的，寫在設定檔的 `permissions.addDirs`（見 [config.md](config.md)）。
  開 xj 時加的換對話也在，`/add-dir remove` 才拿掉。`xj -p` 也照這兩個加，但沒辦法問信任：沒信任過的只能讀。`xj mcp` 不收（它碰得到的資料夾照 `mcpServer.projects`）。
- **事後檢查**改到哪個資料夾就跑那裡的：只改了加進來的資料夾的話，在那個資料夾裡跑它自己的檢查（在那裡開 xj 時用 `/checks add` 加的，和它的 `.xing-janus/checks.json`：
  第一次跑、內容改過時先問），工作目錄的不跑。`/checks` 列的、`/checks run` 跑的照舊是工作目錄的。
- 狀態列的「資料夾 3」是連工作目錄一共幾個（只有工作目錄時不顯示）；全螢幕模式右邊那一欄的「資料夾」點了列出。
  沙盒關掉的時候工具沒有範圍（見上面「沙盒」），寫「不限」。

## 斜線指令

`/help` 列出全部的指令和按鍵（指令列的用法看 `xj --help` 或 `xj -h`）。常用的：

| 指令 | 做什麼 |
|---|---|
| `/model [平台:模型]` | 換平台、換模型；不帶參數的話先選平台、再選模型（↑↓ 移動、Enter 選、數字鍵直接選、Esc 取消）。換了就記進設定檔。見下面「換平台、換模型」 |
| `/key [名字]` | 同一家好幾把 key 的話換一把用（只換這次對話）；不帶參數的話從清單選（列名字和放在哪裡，不顯示內容）。見 config.md 的「同一家好幾把 key」 |
| `/effort low…max` | 推理強度，只列出目前模型支援的 |
| `/undo` | 還原上一輪 `edit`、`write` 改過的檔案，可以連續用（`bash` 改的不能還原） |
| `/diff` | 這次用 `edit`、`write` 改了什麼 |
| `/todo` | 再看一次模型的待辦清單（做到哪裡）；只能看，要改直接跟它說 |
| `/compact` | 把之前的對話濃縮成摘要（上下文到了門檻也會自動摘要） |
| `/clear`、`/resume` | 開新的對話；接續這個資料夾之前的對話 |
| `/checks` | 改檔之後自動跑的檢查（測試、lint）；失敗的交給模型修，最多 3 次。`/checks add <指令>` 加一個（記在 `~/.xing-janus/checks.json`，各專案分開）、`/checks remove <編號>` 拿掉、`/checks off`／`/checks on` 這次對話先不跑／再打開、`/checks run` 現在就跑一次。改到加進來的資料夾的話跑那裡的（見上面「加進來的資料夾」） |
| `/image <路徑>` | 附加一張圖片（也可以把圖片拖進終端機，或在問題裡打 `@路徑`）；`/image clear` 取消還沒送出的圖片 |
| `/mode [模式]` | 切換模式（`normal`、`auto-edit`、`full-auto`、`plan`、`read-only`、`bypass`；Shift-Tab 也能切）；不帶參數列出現在的、切得到的，和這次切不到的原因。見上面「沙盒和模式」 |
| `/sandbox on`、`/sandbox off` | 打開、關掉沙盒（只管這次對話；關掉要按 `y`）；不帶參數講現在的狀態。見上面「沙盒」 |
| `/trust`、`/trust off`、`/add-dir` | 信任這個資料夾、取消信任（都會記下來，下次開也照這個）；`/add-dir <路徑>` 這次對話多一個資料夾（問你只能讀還是也能改），`/add-dir` 列出、`/add-dir remove <編號>` 拿掉（見上面「加進來的資料夾」） |
| `/permissions` | 看權限：現在的狀態和怎麼換、你永久允許的、設定檔改了的、內建的；`/permissions remove 編號` 拿掉，這次對話也馬上生效；全螢幕模式接著開選單（`/permissions menu` 直接開）。見上面「永久允許」 |
| `/config` | 改常用的設定：列出現在的值，選一項就改、講改了會怎樣（↑↓、Enter，Esc 結束）；寫進設定檔，放寬的要按 `y`。見下面「改設定」 |
| `/budget` | 預算：三個上限、花了多少；`/budget day 50` 這樣改。見下面「花費和預算」 |
| `/jobs` | 放到背景的指令：列出、看輸出（`/jobs <編號>`）、停掉（`/jobs stop <編號>`）。見下面「指令的時間上限、背景跑」 |
| `/cost` | 這一輪、這次對話、今天、本月的花費 |
| `/tui` | 全螢幕模式（預設）和一般模式：`/tui fullscreen`、`/tui classic`（會記在設定檔，下次也用它） |
| `/language` | 介面的語言（`/language ui en`、`/language ui zh-TW`，記在設定檔）和這次對話 AI 回覆的語言（`/language reply …`） |
| `/notify` | 提示音（一輪跑完、要問你的時候響一聲）：`/notify on`、`/notify off`，不帶參數就切換；只在這次對話（預設照設定檔的 `notify`） |
| `/exit` | 離開（輸入是空的時候連按兩次 Ctrl-C，或按 Ctrl-D，也會離開） |

輸入：Enter 送出；行尾打 `\` 或按 Alt-Enter 換行（貼上的多行文字不會被拆開）。Tab 補完斜線指令和它的參數（`/image`、`/add-dir` 補完路徑），↑ ↓ 叫出之前打過的。

## 換平台、換模型（/model）

打 `/model`（不帶參數）先選平台、再選它的模型。平台有四種：Anthropic、OpenAI、Gemini、OpenAI 相容的服務（本機的 Ollama、LM Studio、llama.cpp、vLLM…，
雲端的 OpenRouter…）。選單上標出：

- 在這台（`localhost`、`127.0.0.1`、`::1`），還是連到哪一台（網址的主機；區網裡別台電腦的 Ollama 也是「連到」別台）
- 金鑰放在哪裡、還沒設（Anthropic、OpenAI、Gemini 要金鑰；OpenAI 相容的服務可以不用）
- 這台找到的本機伺服器：打開選單時問一下這台常見的埠（Ollama 11434、LM Studio 1234、llama.cpp 8080、vLLM 8000，只問這台、等不到一秒），
  回得出模型清單的列出來；選了才寫進設定檔的 `providers`
- 最後一項「新增一個 OpenAI 相容的服務」：名字、網址、金鑰（可以不給），查得到模型清單才寫進設定檔

還沒設金鑰的那一家（或服務不接受沒有金鑰的請求，例如 OpenRouter）：選了就當場貼上金鑰。畫面上只顯示 `•`，不進輸入的歷史、對話紀錄；
先用它查一次模型清單，查得到才存，存的地方跟 `xj setup` 一樣（鑰匙圈、認證管理員，存不進去的話是只給你讀的金鑰檔）。
網址是沒加密的 `http://`、又不在這台的：金鑰會以明文送出，xj 不送、也不在這裡設（見 config.md 的「接別的模型服務」）。
輸入不是終端機（管線）的時候不能這樣設，用 `xj setup`。同一家選的是有名字的那一把（`keys`）的話也不能在這裡設：照「同一家好幾把 key」放好那一把。

換到別的平台之前，先查一次那一家的模型清單：連不上、金鑰被拒就不換，照舊用原本的。對話有內容的話先問你：之前的對話（包括它讀過的檔案內容）
會轉成文字送到那一家（問的時候講送到哪一台）；太長的話先用原本的模型摘要（多一次請求）。換到這台的平台時對話不離開這台，只有要先摘要的時候才問。

換了就記進設定檔的 `defaultModel`（跟 `/tui` 一樣），下次開 xj 也用它；寫不進去的話會講，只換這一次。
直接打 `/model 平台:模型`（例如 `/model ollama:qwen3`）也一樣：缺金鑰當場設、先確認連得上、要送到別台電腦先問、換了就記住。

## 做事的時候也能打字

模型在做事的時候，輸入列照樣開著（全螢幕模式在最底下；一般模式在狀態列那一行）：

- 打好按 Enter，這句話先**排隊**（全螢幕模式畫在輸入列上面），模型做完手上這一步（下一次工具呼叫之前）就交給它；它已經講完了的話，同一輪接著回你。
  交給它的那一刻才印進對話裡，順序跟模型看到的一樣。
- 拿來補充細節、更正、喊停都可以：「第 2 項不用做了」「改用 TypeScript」「先不要動測試」。
- 這時候打的斜線指令等這一輪做完才執行（不會在模型做到一半時換模型、換對話）。
- 輸入列是空的時候按 Ctrl-C 中斷這一輪（有字的話先清掉字）。中斷時還沒交給它的話不會自動送出，會列出來，要的話再送一次。
- 開場還在準備（例如開沙盒）的時候按 Ctrl-C：收尾、結束，不用等開場做完；正在問你的（例如要不要信任這個資料夾）按 Ctrl-C 算「否」。
- 你打字打到一半、剛好跳出權限詢問的話，那一下按的鍵不算回答（不然句子裡的 `y` 會被當成「是」）：停一下、看清楚再按。

## 畫面：誰在說話

每一行左邊有一欄標出是誰：

```
你 ▏請建 hello.txt

AI ▏好的，我先列計劃。
   ▏  建立 hello.txt
xj ▏▍ ── 建立 hello.txt ──
   ▏▍ 套用？  [y] 是  [n] 否  y
AI ▏    ✓ 已建立 hello.txt（+1 −0 行）
   ▏建好了。
   ▏  本輪 約 $0.01
```

- **你**：你打的字、斜線指令。**AI**：模型的回覆、它用的工具和結果、這一輪的花費。**xj**：Xing Janus 自己講的（斜線指令的回覆、權限詢問、提醒和錯誤）。
- 模型裝不出 xj 在說話：每一行最前面那幾格（中文介面 4 格、英文介面 5 格；終端機把寬度不明確的字當成兩格時，`▏` 多佔一格）一定是 Xing Janus 畫的，模型的字從它們後面開始；那條 `▏` 跟詢問的 `▍` 一樣，模型的字、檔名、指令輸出都印不出來。

## 全螢幕模式

預設就是全螢幕模式，像 vim、htop 一樣整個畫面由 Xing Janus 畫。想用終端機自己的捲動、搜尋、選取複製，打 `/tui classic` 換成一般模式（記在設定檔的 `screen`，下次也用它），`/tui fullscreen` 換回來：

- 視窗夠寬（100 欄以上）的時候，右邊有一欄：上面是待辦清單（這一輪的子代理、在跑的背景的指令也列在這裡），下面是**目前的狀態**和常用指令。不夠寬時待辦清單放在輸入列上面（最多 5 項），狀態看最底下的狀態列。
- 狀態那一段每一項前面有一個色塊，後面寫目前是什麼：模式、沙盒、資料夾、信任資料夾、改檔都允許（詢問時按了 `a`）、永久允許、今天的預算、事後檢查、Enter＝是、提示音。
  色塊：**綠**開著、**灰**關著、**黃**開著但比較寬鬆（問得比較少）、**紅**要注意（沒有沙盒、全部不問模式、預算到了上限）。看字就知道，色塊只是輔助（`NO_COLOR` 時沒有顏色）。
  - 模式底下一行灰字講在現在的沙盒狀態下實際怎麼做（例如一般模式「改檔先問；白名單直接跑」，沙盒關掉時「改檔先問；指令都問」）。
  - 沙盒關掉時寫是哪裡關的（「關（設定檔）」「關（指令列）」「關（/sandbox）」；Windows 還沒裝沙盒是「沒裝好」，起不來是「起不來」），
    底下一行講網路（開著時「網路：允許的 3 個網域」，全部不問模式「網路：3 個，其他擋下」）或指令碰得到哪裡（關掉時「指令碰得到整台電腦」）。
  - 資料夾：只有工作目錄時寫「工作目錄」；加了的話寫連工作目錄一共幾個，底下一行列出名字（「能改：api　只能讀：docs」，有也能改的標黃）。
    沙盒關掉時寫「不限」（工作目錄以外的讀、改每次都問，黃；全部不問模式不問，紅）。
  - 模式本來就不問改檔時（自動改檔、全自動、全部不問），改檔都允許寫「這個模式用不到」。
- **點一下**（同一行按下、放開）：每一項後面的灰字寫點了會做什麼（切換、收回、列出）；點了不會切換的（信任資料夾、關著的改檔都允許），下一行寫怎麼改。提示音、Enter＝是切換開／關（只在這次對話）；模式換下一個（跟 Shift-Tab 一樣）；
  沙盒跟打 `/sandbox off`、`/sandbox on` 一樣（關掉要按 `y`；模型在跑的時候講等這一輪做完）；
  改檔都允許開著的時候點一下就收回（關著的點了不會打開：要在改檔的詢問時按 `a`）；信任資料夾只講怎麼改，不會切換；
  資料夾、事後檢查列出內容（跟打 `/add-dir`、`/checks` 一樣），永久允許開 `/permissions` 的選單，今天的預算就是 `/budget`，上半部在跑的背景的指令點了看輸出（`/jobs <編號>`）：
  這幾個在模型跑的時候講等這一輪做完再看。常用指令裡的斜線指令填進輸入列（看過再按 Enter），Shift-Tab、Ctrl-C 直接照按那個鍵（切換模式、中斷這一輪）。點了之後最下面那一行講改了什麼。貼上的內容裡夾著的滑鼠控制碼不算點擊。
- 視窗矮的時候，狀態那一段先拿掉每一項底下的那一行灰字，再收掉常用指令，待辦清單照樣看得到。
- 捲動：PageUp／PageDown、滑鼠滾輪。往上捲的時候新的輸出不會把畫面拉下去（最底下會講還有幾行沒看）；送出新的訊息就回到最底下。
- **選取、複製**：在對話那一欄拖曳就反白，放開就複製到剪貼簿（只選對話的字，不含左邊的標籤和右邊那一欄；被折下來的長句接回一行）。點一下或按任何鍵，反白就收掉。
  反白還在的時候按 Ctrl-C 是複製、不會中斷（跟 Windows Terminal 一樣：有選取時 Ctrl-C 是複製，沒有才是中斷）；這一輪還在跑的話，狀態列會講「要中斷這一輪，再按一次 Ctrl-C」。
  在 SSH 連線裡、或 Linux 沒有 wl-copy／xclip／xsel 時，交給終端機（OSC 52：iTerm2、tmux、Windows Terminal 支援，Terminal.app 不支援）。
  想用終端機自己的選取：iTerm2 按住 Option 拖曳，或打 `/tui classic` 換成一般模式。
- 終端機自己的搜尋（Cmd+F）找不到全螢幕裡的對話。離開全螢幕（`/tui classic`、離開 xj）時，整段對話會印回一般的畫面，之後就找得到了。
- 輸出不是終端機、`TERM=dumb`、視窗太小、舊的 Windows 主控台時開不了，照舊用一般模式。

## 不互動的模式（給腳本用）

```bash
xj -p "這個專案的測試指令是什麼？"
git diff | xj -p "幫這段改動寫一行 commit 訊息"
```

回覆印到 stdout，工具動作和花費印到 stderr（`-p` 也可以寫成 `--print`）。要問你的動作（改檔、不在白名單的指令、新的網域）一律拒絕；沒問過信任的資料夾當成不信任。
設定檔的預設模式是自動改檔或全自動的話，`-p` 用一般模式（改檔要問，所以一律拒絕）；要全自動就明確加 `--auto`。
第一次使用要先在終端機裡跑一次 xj、同意使用提醒：還沒同意的話，`xj -p` 直接結束（exit 2）。

同一家好幾把 key 的話，`xj -p --key work "…"` 用 work 那一把（沒加就照設定檔的 `keys` 選）；那一把被拒時，`keys.<廠商>.onReject` 是 `"ask"` 的話一律不換（沒有人能回答）。

從管線傳進來的內容是資料，不是你打的問題：裡面的 `@路徑` 不會附加檔案。要附加，寫在 `-p` 的問題裡（`git diff | xj -p "對照 @docs/style.md 檢查這段改動"`）。

## 讓別的程式叫 xj（MCP）

`xj mcp` 讓 Claude Desktop、IDE、你自己寫的通訊軟體橋接這類程式透過 MCP 叫 xj 做事。預設唯讀、只有啟動它的那個資料夾；
能做什麼、能用哪些專案在設定檔的 `mcpServer` 自己決定。怎麼接、放寬的風險、給插件的介面：[mcp-server.md](mcp-server.md)。

## 狀態列

最底下一行：模型 · 金鑰（同一家好幾把 key 的話用的是哪一把；只有一把的話不顯示） · effort · 模式 · 沙盒 · 資料夾（加了資料夾才有：連工作目錄一共幾個） · 背景（有背景的指令在跑時：幾個） · 上下文（用了多少／摘要的門檻） · 待辦（有還沒做完的待辦清單時，例如「待辦 2/5：正在寫測試」） · 這一輪的花費（模型在跑的時候） · 今天的花費 · 本月的花費（花費都跟上限比，例如「今日 約 $3.10/$30」）。工作中顯示最新的進度。視窗太窄時從最後面開始省略。沙盒關掉時寫是哪裡關的（「沙盒關（設定檔）」這類）；全部不問模式又沒有沙盒時整列標紅。
要哪些欄位、什麼順序，寫在設定檔的 `statusBar.fields`（自己寫了這一欄的話，新的 `folders`、`jobs`、`turn-cost` 要自己加進去）。

上下文那一欄後面有 **`?`** 的話，表示查不到這個模型的能力，用的是保守的預設值（上下文 32k、輸出 8k）——
自訂的服務常常這樣。真實的值可以寫進設定檔的 `capabilities`（見 [config.md](config.md)），不然你會只用到模型的一部分。

## 待辦清單

做多步驟的工作（改一個功能、修一串測試、你一次交代好幾件事）時，模型會先列一張待辦清單，做一項標一項：

```
  更新待辦清單
    ✓ 讀現有的程式
    ► 寫測試
    ☐ 實作
```

- 每次更新都印出整張（全螢幕模式畫在右邊或輸入列上面，不印進對話裡）；狀態列顯示做到第幾項、正在做什麼。`/todo` 隨時再看一次。
- 清單只列你這次交代的那件工作。做完了狀態列的待辦就不見；再交代新的工作，換成新的一張（不會越積越多）。
- 你不用管這張清單，直接跟它說就好（它在做事的時候也可以說，見下面的「做事的時候也能打字」）：多交代的事它會加進清單（之前做完的留著）；
  說「第 3 項不用做了」「README 那一項改成英文」，它會找出是哪一項、改掉或刪掉。清單有編號，畫面上的編號跟它看到的一樣。
- 清單不碰檔案、不跑程式，所以不會問你（唯讀、計劃模式也能用）。
- 清單只存在這台電腦（xj 的記憶體和 `~/.xing-janus/sessions/` 的對話紀錄，給 `/resume` 用），沒有另外送到別的服務；清單是模型寫的，本來就是跟模型的對話的一部分。
- 摘要之後、`/resume` 接續時清單還在（摘要之後也會再給模型看一次，免得它忘了還剩什麼）；`/clear` 開新的對話就清空。
- 一步就做完的事、單純的問答，模型不會列清單。每個模型都有這個工具；不想讓某個模型用，在設定檔的 `capabilities` 寫 `"todoTool": false`（例如 `"anthropic:claude-opus-5-5": { "todoTool": false }`）。

## 抓網頁

模型可以抓一個網址來看（查套件的文件、changelog、GitHub 上的 issue），工具叫 `web_fetch`：

- 只用 GET，不帶 cookie、不帶你的任何登入資訊。只收文字（HTML 轉成純文字，標題、清單、程式碼、連結留著，script、style 拿掉）；
  圖片、PDF 不收。一頁最多下載 5 MB、30 秒；給模型的最多 4 萬字，太長的它會接著往下讀。同一個網址 15 分鐘內再抓用上次的結果。
- **網域要問**，跟沙盒的網域同一份清單（見上面的「權限詢問」）；問的時候整個網址看得到。永久允許寫進 `sandbox.allowedDomains`。
- **網址裡有看起來像金鑰的字**：允許過的網域也問，而且只能允許這一次（網址會送到那個網站，它看得到）。
  換個寫法也算：前面多接一個字、百分比編碼（`%2D`）、放在路徑裡。編碼成 base64 之類的看不出來，所以允許過的網域照樣要你自己判斷（見 cerberus.md）。
- **不問就擋**：本機（`localhost`、`127.0.0.1`）、直接寫成內網位址的（`10.x`、`192.168.x`…）、雲端的 metadata 位址、帶帳號密碼的網址（`user:pass@`）、
  藏在 IPv6 寫法裡的這些位址（NAT64、6to4）、這台機器自己的位址、連接埠 0；
  名稱解析到本機、metadata 的也擋（連線用的就是檢查過的那個位址）。名稱解析到內網的照樣問你，不直接擋（公司或組織內部的文件網站才用得了）。
  要抓本機的開發伺服器，在設定檔的 `sandbox.allowedDomains` 寫明（例如 `127.0.0.1:3000`）。
- **轉址**：同一個網站的照跟（最多 5 次）；轉到別的網站的不跟，把新網址告訴模型，它要抓的話是新的網域，會再問你。
- 抓到的內容給模型時標明是網頁的內容（資料，不是指令，見 [cerberus.md](cerberus.md) 的「提示注入」）；畫面上只印抓了多少字，不印內容。
- 唯讀、計劃模式、不信任的資料夾也能用（只是讀，網域照樣問）。全自動模式照樣問網域；全部不問模式：沒有沙盒時不問網域，沙盒開著時只到允許過的網域、沒允許過的不問就擋；上面「不問就擋」的都照樣擋。
  不互動的模式（`xj -p`）沒允許過的網域一律拒絕。
- 沒有搜尋：要它查的話，給它網址，或讓它自己找文件的網址。
- 不想讓某個模型用：設定檔的 `capabilities` 寫 `"webFetch": false`。

## 子代理

模型可以把一件事交給子代理去做：子代理在自己的上下文裡讀檔、搜尋、改檔，做完只把報告交回來，主對話不會被它讀的一大堆檔案塞滿；
幾件獨立的調查可以同時跑。

- 每個模型都有這個工具。它通常自己做，你要它分頭去查、交給子代理改的時候直接講（「用兩個子代理同時查 A 和 B」）。
  不想讓某個模型用：設定檔的 `capabilities` 寫 `"subagents": false`（例如 `"anthropic:claude-opus-5-5": { "subagents": false }`）。
- **兩種**：`explore` 找東西、讀程式，**一定是唯讀**，最多同時 4 個；`general` 會改檔、跑指令，一次一個。
- **權限跟主對話一樣**：子代理的每個動作都經過 Cerberus（同一套權限、沙盒、機密檔、允許過的網域），不比主對話寬：
  - `explore`：主對話是全自動、全部不問也照樣是唯讀。
  - `general`：照主對話的模式（一般模式改檔照樣秀 diff 問你）；唯讀、計劃模式、不信任的資料夾開不了。
  - 要問的時候，詢問的第一行寫是哪個子代理（「子代理「改 README」：修改 README.md」）。**答應的是你**，主代理不能替你答應。
    沙盒裡的指令（例如 curl）要連新網域時是例外：那是沙盒的代理程式問的，只知道要連哪裡，看不出是哪個子代理的指令。
  - 好幾個詢問接連跳出來（同時跑的子代理）：下一個剛跳出來的半秒內按的鍵不算，連按兩下不會答到下一題。
- **畫面**：一個子代理一行。全螢幕模式跑的時候那一行會更新（做了幾個動作、改了幾次、花多少），做完換成結果；一般模式開始、做完各印一行。
  全螢幕模式的寬視窗右邊那一欄，待辦清單下面列出這一輪的子代理（幾個在跑、各做到哪裡），這一輪結束就收掉。
  子代理的每個動作不一一印出來（要問你的照常跳出來）。
- **改了什麼由 xj 算**：`general` 做完，交給主代理的除了報告，還有 xj 自己算的「改了哪些檔、各加減幾行」（不是子代理說的），
  主代理被交代回覆你之前要看過這些改動、跑過測試。`/undo` 照樣還原整輪（子代理用 edit、write 改的也算），事後檢查照樣跑。
- **模型**：預設跟主對話同一個。要換的話直接講（「用 Haiku 去找」），或在設定檔寫 `subagents.model`（寫法跟 `/model` 一樣，例如 `anthropic:haiku`）。
  用的不是主對話的模型時，那一行會標出來。模型自己要換到別家的模型時會先問你（交代的內容和它讀到的東西會送到那一家），
  設定檔的 `subagents.model` 是你自己設的，不問。主對話沒給的工具（例如能力表關掉的 `web_fetch`），換了模型也拿不到。
- **上限**：每個子代理最多 30 個工具呼叫、10 分鐘，到了就叫它把找到的交回來。花費算進這一輪，每輪的預算照樣有效；
  它做的動作也算進每輪的工具呼叫上限（到了照樣停下來問你）。
  都可以在設定檔的 `subagents` 改（見 [config.md](config.md)）。
- 子代理不能再開子代理，也不能用待辦清單、MCP、技能、背景的指令、提議改設定。完整的過程存在對話紀錄旁邊的 `subagents/`（`/resume` 只接主對話）。

## 指令的時間上限、背景跑

- 指令（bash、PowerShell）預設跑 2 分鐘就收掉（整個行程群組），模型最多可以指定 10 分鐘：設定檔的 `commands.timeoutSec`、`commands.maxTimeoutSec`（見 [config.md](config.md)；
  `/config` 的「指令的時間上限」也改得到，下次開 xj 起照新的）。逾時的那一行會講是哪一欄、現在是多少。
- 很久的（整套測試、第一次 build、開發伺服器）**放到背景跑**：模型在指令加上 `background`，馬上拿到一個編號，之後用 `job_output` 看輸出、等它跑完（不用一直問），
  用 `job_stop` 停掉。照樣經過同一套詢問（問你的時候會講這是放到背景跑的、最多跑多久）、在沙盒裡跑；最長跑 60 分鐘（`commands.backgroundMaxMinutes`，0 是不限，例如開發伺服器）。同時最多 8 個。
- **看得到、停得掉**：狀態列的「背景 2」；全螢幕模式右邊那一欄上半部列出在跑的（跑了多久，點了看輸出）；
  `/jobs` 列出來、`/jobs <編號>` 看輸出的最後一段（完整的在這個 session 的 `outputs/job-<編號>.log`）、`/jobs stop <編號>` 停掉（整組收掉）。
- **印太多的會停掉**：一個背景的指令最多印 5 GB（寫錯的腳本一直印同一個錯誤，一分鐘可以寫到 1 GB 以上），超過就停掉、講原因；輸出檔只留開頭和最後一段。
- **結束的時候**對話裡記一行（提示音開著、這一輪沒在跑的話響一聲）。模型在跑的話，下一個工具結果附一行告訴它；這一輪已經結束的話，你下一次送出時告訴它（不自己開新的一輪：會花錢）。
- 背景的指令照開始時的沙盒跑：有在跑的時候要換沙盒（`/sandbox`），先問你、停掉再換。`/exit` 時還有在跑的也先問（離開的話一起收掉）；xj 結束時一律收掉。
- Windows 的沙盒：要重新擋檔案的時候（機密檔被換成另一個檔案、拿掉了資料夾、加了也能改的資料夾），背景還有指令在跑的話下一個指令不會跑，
  xj 講要先停掉哪幾個；停掉再跑一次就好（原因見 [troubleshooting.md](troubleshooting.md) 的「Windows 的沙盒跟 macOS、Linux 不一樣的地方」）。
- `xj -p`、`xj mcp`、子代理不能放到背景（沒有人看著；子代理一輪結束就收）。輸出跟一般的指令一樣遮掉金鑰。

## 花費和預算

畫面上的金額都標「約」：那是**預估**（本機價格表 × 用量），不是帳單 —— 服務商會調價，實際金額以他們的帳單為準。

每一輪、每天、每月都有上限（設定檔的 `budget`，預設每輪 $5、每天 $30、每月 $100；填 0 等於關掉那一項），到 80% 提醒、到 100% 停下來問你（那一句會講怎麼調高）。

- **`/budget`**：列出三個上限、花了多少、怎麼改（同一家好幾把 key、某一把另外設了上限的也列）。`/budget turn 10`、`/budget day 50`、`/budget month 200` 改上限（填 0 是不設上限）：
  先問只這次對話（Enter）還是也寫進設定檔；寫進設定檔要再按 `y`（只改那一欄，寫之前整份檢查過）。模型自己改不了預算（可以提議，你答應才寫，見下面「改設定」）。`xj mcp` 照舊用 `mcpServer.budget`。
- 狀態列：「今日 約 $3.10/$30 · 本月 約 $12/$100」，模型在跑的時候多一欄「這輪 約 $0.40/$5」（`statusBar.fields` 的 `turn-cost`）。
- 全螢幕模式右邊那一欄的「今天的預算」：值是今天的，底下一行這一輪（在跑的時候）和本月；平常綠，有一項到 80% 黃、到上限紅；點了就是 `/budget`。
- `/cost` 也列這一輪、今天的上限。`xj setup` 不問預算，最後講一句預設的上限和 `/budget`。價格表在 `~/.xing-janus/prices.json`，每一筆都寫了來源和日期；超過三個月沒更新，`xj doctor` 會提醒。本地模型（Ollama）算 $0。服務沒有回報用了多少 token 的請求，花費顯示「未知」（不會當成 $0），一輪裡累積太多個會停下來問你。

## 改設定（/config、問 xj）

設定檔（`~/.xing-janus/config.json`，每一欄見 [config.md](config.md)）有三種改法：

- **`/config`**：列出常用的設定和現在的值（開 xj 時開沙盒、預設模式、允許切到全自動、允許切到全部不問（只能看）、預算、指令的時間上限、介面語言、提示音、Enter＝是、畫面、一起加的資料夾），
  選一項就改，每一項講改了會怎樣。放寬的（關沙盒、比較寬的預設模式、允許切到全自動、調高預算和時間上限、記下能改的資料夾）要按 `y`（Enter 不算）；只改那一欄，寫之前整份檢查過。
  預算、介面語言、提示音、Enter＝是、畫面這次對話也馬上換；其他的（沙盒、預設模式、允許切到全自動、指令的時間上限、一起加的資料夾）下次開 xj 起照新的
  （這次對話的沙盒、模式用 `/sandbox`、Shift-Tab 換）。
  「一起加的資料夾」把這次對話 `/add-dir` 加的記下來（下次在這個資料夾開 xj 時一起加，寫進 `permissions.addDirs`），或拿掉記下來的。
- **問 xj**：直接問，例如「這個專案要用 docker，該怎麼設？」。xj 附了一個內建的技能 `xj-settings`（每個設定做什麼、你的情況該怎麼設、哪些要你自己改），模型用到才讀；
  讀的時候看得到你現在的設定：設定檔照寫的（金鑰、MCP server 的環境變數和參數、網址裡的帳號密碼和查詢字串遮掉），加上這次對話的模式、沙盒、資料夾、預算。
  模型可以**提議**改設定（`settings_propose`）：xj 照設定檔的規則驗過，每一項標「放寬」「收緊」或「不影響權限」、講會影響什麼，像改檔一樣先問你（放寬的標紅、要按 `y`；全部不問模式也問），
  答應了才由 xj 自己寫（模型照舊寫不了設定檔）；問你的時候設定檔被改過了就不寫。模式、允許切到全自動、預算、白名單（`permissions.allow`）、網域（`sandbox.allowedDomains`）
  這次對話也馬上生效，其他的下次開 xj 起（沙盒、資料夾會講這次對話怎麼換）。
  模型不能提的（要你自己改）：全部不問（`allowBypass`、`defaultMode: "bypass"`）、關掉「全部不問時刪掉重要的地方照樣問」、拿掉內建的危險規則和機密檔、MCP server、`xj mcp` 的設定、
  金鑰和服務、環境變數。白名單、沙盒外的指令只收「永久允許」那種（指令加最多兩個子指令），網域不收 `*`，路徑不收家目錄、放憑證的地方、`~/.xing-janus`。
  不信任的資料夾不收放寬的提議（讀到的檔案可能叫模型這樣提）；`xj -p`、`xj mcp`、子代理不能用。
- **自己改設定檔**：用 VS Code 這類編輯器開，有補完和每一欄的說明（`$schema`）；`xj doctor` 照格式檢查。改了之後重開 xj。

## 專案規則、技能、MCP

- **AGENTS.md**（有 CLAUDE.md 也讀）：寫給 coding agent 的規矩，例如測試指令、程式風格。只在信任的資料夾讀。
- **技能**：`~/.xing-janus/skills/<名稱>/SKILL.md`，或專案裡的 `.agents/skills/`、`.claude/skills/`（專案裡的只在信任的資料夾讀；同名的話用你自己的）。平常只把名稱和說明告訴模型，用到才讀內容。
  xj 自己附了 `xj-settings`（見上面「改設定」；開場不列）：你自己的同名技能會換掉它，專案裡的換不掉。
- **MCP server**：只接設定檔列出的，預設在沙盒裡跑，每次呼叫都會問（設定檔的 `autoApprove` 列的、全部不問模式除外）。

## Flutter 專案

不用另外設定。沙盒開著時 `flutter`、`dart` 在沙盒裡跑不了：模型會要求在沙盒外跑那一個指令、每次問你（config.md「沙盒裡跑不了的工具」；全部不問模式不問就擋，見上面「全部不問模式」），用的是你自己的環境（`JAVA_HOME`、`ANDROID_HOME` 預設就帶過去）；Windows 的沙盒也因此不再開放 Flutter SDK、Pub cache，開得比較快。沒有沙盒時照一般的規則。

## 語言

介面（xj 印的每一句）有英文和繁體中文。第一次啟動時會問要哪一種（預設是系統的語言），記在設定檔的 `uiLanguage`；之後隨時用 `/language ui en`、`/language ui zh-TW` 換。
給模型的說明和工具結果一律是英文；AI 用什麼語言回你是另一個設定：設定檔的 `language`（預設跟介面一樣），或 `/language reply <語言>` 只改這次對話。
