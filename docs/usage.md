# 使用說明

## 模式

| 模式 | 改檔 | 跑指令 |
|---|---|---|
| 一般（預設） | 先秀 diff 再問：是／否／這次對話的改檔都允許 | 白名單的直接跑，其他的問 |
| 自動改檔 | 不問，直接改（畫面照樣印出改了什麼） | 同上 |
| 全自動（要啟動時加 `--auto`） | 不問 | 在沙盒裡跑的都不問；危險清單上的指令、連新的網域、不在白名單的 PowerShell 指令、MCP 還是會問 |
| 全部不問（要啟動時加 `--dangerously-skip-permissions`） | 不問 | 都不問，**沒有沙盒**；只剩直接寫出名字的機密檔、受保護的檔案照樣擋（`grep -r` 這類間接的讀法擋不到） |
| 計劃 | 不准改 | 只准跑白名單裡的唯讀指令；它提出做法，你核准後切到一般模式開始做 |
| 唯讀 | 不准改 | 只准跑白名單裡的唯讀指令 |

- 危險的指令（`rm -rf`、`git push`、`sudo`…）都要問，標紅講原因。唯一的例外是全部不問模式。
- 用 `/mode` 或 Shift-Tab 切換。不信任的資料夾只能用唯讀和計劃模式。切換時對話裡會記一行「模式：一般 → 自動改檔」（放寬的用黃色）；
  一般模式下正在打字時按的 Shift-Tab，等你送出那一句才記（不然會弄亂輸入列）。

### 全自動模式

`xj --auto` 啟動（或設定檔的 `defaultMode` 設成 `"full-auto"`），之後 Shift-Tab 才切得到它。改檔和沙盒裡的指令都不會先問你，
由沙盒當安全邊界。只能在**信任的資料夾**、**沙盒開著**的時候用：`--no-sandbox`、Windows 還沒裝沙盒、或沙盒有一部分擋不到
（Windows 的專案太大、機密檔沒找完）的時候都進不去，會從一般模式開始並講原因。

還是會問：危險清單上的指令、連新的網域、不在白名單的 PowerShell 指令（PowerShell 的字串拼得出任何路徑和指令）、MCP 的呼叫，還有認不出是不是機密檔的情況
（例如有多個名字的檔案）。還是一律擋：機密檔、之後會在沙盒外被執行的檔案（`.git/hooks`、`.vscode/tasks.json`…）。預算的上限照樣有效。

沙盒擋不到的事要你自己留意：

- **工作目錄裡的東西**：沙盒本來就讓指令改工作目錄，危險清單以外的刪除、覆寫不會問；指令改的檔案 `/undo` 還原不了。**開始前先 git commit。**
- **你之後在沙盒外跑的東西**：原始碼、`package.json` 的 scripts 本來就是它的工作範圍。**在沙盒外跑 build、`npm start` 之前，先看過 `git diff`。**
- **允許過的網域**：已經允許的網域，沙盒裡的程式送東西過去不會再問。
- **檔案裡藏的指示**：被誘導的話，危險清單以外的事都會直接做。只在你信任的程式碼裡用。

改回信任（`/trust`）之後不會自己回到全自動，要你再切一次。`xj -p` 只有明確加 `--auto` 才用全自動（設定檔的不算）。

### 全部不問模式

`xj --dangerously-skip-permissions` 啟動。**沒有沙盒**，改檔、指令（包括危險清單上的）、PowerShell、MCP 的呼叫都不會先問你；
MCP server 也在沙盒外跑。指令能做你的帳號能做的任何事：刪檔案、讀家目錄裡的 SSH 金鑰和雲端憑證、連任何網站、用 Docker。
檔案、網頁裡藏的指示（提示注入）可以直接叫它做這些事。**只在可以整個丟掉的環境（容器、虛擬機）裡用，開始前先 git commit。**

- **照樣一律擋**：直接寫出名字的機密檔（`cat .env`、讀金鑰檔…）、受保護的檔案（`.git/hooks`、`.vscode/tasks.json`…）。認不出是不是機密檔的（有多個名字的檔案）照樣問。
- **擋不到間接的讀法**：沒有沙盒，xj 只看得到指令的字。`grep -r`、`cat *`、`find -exec cat`、`tar`、PowerShell 的 `Get-ChildItem | Get-Content`、
  或模型自己寫的程式，都讀得到資料夾裡的 `.env`，讀到的會送到模型服務（2026-10-21 實測）。**機密別放在這個資料夾。**
- **切換成 root 照樣問**：`sudo`、`su`、`doas`、`pkexec`（包在 `env`、`bash -c` 裡面的也算），PowerShell 的 `-Verb RunAs`、`runas`、`sudo`。
  要讓 `sudo` 不問，在設定檔的 `permissions.dangerRemove` 加 `"sudo"`（一般模式也會跟著不標紅）。這只管 bash 的 `sudo`：PowerShell 的 `-Verb RunAs`、`runas` 照樣問。
- **用 root 跑的時候開不了**：`sudo xj --dangerously-skip-permissions`、或容器裡預設的 root 都會被擋下來，請改用一般帳號。
  Windows 上「以系統管理員身分執行」的終端機也一樣（問不到是不是的時候當成是）。
  在可以整個丟掉的容器裡、又一定要用 root 的話，設環境變數 `XING_JANUS_ALLOW_ROOT_BYPASS=1` 再開。
- **照樣有效**：預算的上限、每輪工具呼叫次數的上限。
- **每次都要確認**：啟動時先印警告和使用提醒，要你自己打「我了解風險」再按 Enter（貼上的不算，Esc 取消）。不能寫進設定檔當預設。
- **只能在信任的資料夾用**：不信任的話照平常的模式開始（有沙盒）。
- 狀態列整列標紅、寫「全部不問模式」。Shift-Tab 可以切到別的模式，但這次對話沒有沙盒，所以切出去之後每個指令都要問。
- **Windows：沙盒的帳號寫得進 PATH 上的資料夾時**。開沙盒時發現的話，xj 會用系統管理員權限跑 `icacls` 把它擋掉
  （只擋沙盒的帳號寫入；Windows 會跳 UAC，你按了才會跑；在背景跑，不用等）：
  - 沙盒開著：輸入列出來之前**問你一次**（是／否／永久允許）。選「永久允許」就是設定檔的 `sandbox.autoFixWritable` 寫成 `true`，
    之後發現就不問（`/permissions` 看得到、拿得掉）。按「否」就不擋，同樣的地方之後不再問（開沙盒時照樣講白名單不生效）。
  - 全部不問模式：照上次開沙盒時記下的，**不問就擋**。
  - UAC 按「否」或沒擋成就不再自動跑，改印指令讓你自己跑。`-p` 這種沒有人能回答的只印指令。
  - 記錄在 `~/.xing-janus/acl-fix.json`（沙盒讀寫不到），擋之前會核對那是沙盒帳號現在的 SID。
- `xj -p --dangerously-skip-permissions`：沒有人能打字確認，加了旗標就算同意，警告和使用提醒印到 stderr；不信任的資料夾直接結束（exit 2）。
- 不能跟 `--auto` 一起用。

## 權限詢問

- **改檔**：`y` 套用、`n` 不要、`a` 這次對話的改檔都允許。
- **指令**：`y` 執行、`n` 不要。被拒絕的時候，它會換別的方法，不會重試同一件事。
- **Windows**：bash 用的是 Git Bash（白名單、危險清單跟 macOS、Linux 一樣）；另外有 PowerShell，它的白名單只認很單純的唯讀寫法
  （`Get-ChildItem`、`Get-Content`、`Select-String`…，參數是一般的字或單引號），唯讀、計劃模式也只能跑這些；其他的每個都問。
  沒裝 Windows 的沙盒時，bash、PowerShell 的指令都每個都問。
- **網域**：沙盒裡的指令、`web_fetch`（抓網頁）要連一個沒列過的網域時會問：`o` 允許一次、`s` 這次對話都允許、`p` 永久允許、`n` 拒絕。
  兩邊用同一份清單：`curl` 允許過的網域，抓網頁不再問，反過來也一樣。
- **Enter 就是「是」**：預設開（跟 Claude Code 一樣；設定檔寫 `"enterToApprove": false` 就一律要按 y）。一般的詢問按 Enter 就答應（選項上會寫 `[y/Enter]`），網域的詢問是「允許一次」。
  危險的指令、還沒看完的內容（要先按 `v`）、永久允許的確認照樣要按 `y`；詢問剛出現的 0.5 秒內的 Enter 不算。
- **永久允許（`p`）**：寫進設定檔，**所有專案都適用**。按了之後還會再問一次，列出要寫進哪個檔、哪一欄、寫什麼，按 `y` 才寫（`n` 回到原本的問題）。
  有這個選項的：沙盒裡的網域（寫進 `sandbox.allowedDomains`）、單純的指令（寫進白名單 `permissions.allow`，寫的是指令加上子指令，
  例如 `npm test`：之後 `npm test --watch` 也算）、MCP 工具（寫進那個 server 的 `autoApprove`）。
  沒有這個選項的：危險清單上的指令、在沙盒外跑的指令（`excludedCommands`）、有 `&&`、管線、重新導向的指令、光一個 shell 或直譯器（`node`、`python`、`bash`）、
  PowerShell 白名單外的指令、改檔（要的話把預設模式設成自動改檔）。機密檔照舊只能自己改設定檔。指令的永久允許只在沙盒開著、信任的資料夾裡才有（寫進白名單才會直接跑）。
  永久允許的東西用 `/permissions` 看、拿掉。
- 真的詢問，標題和要你回答的那一行最前面有 `▍`，左邊的標籤是「xj」。模型的文字、檔案內容印不出這個記號：看起來像詢問、前面卻沒有它的，是模型寫的字，不是 Xing Janus 在問你。

## 斜線指令

`/help` 列出全部。常用的：

| 指令 | 做什麼 |
|---|---|
| `/model [廠商:模型]` | 換模型；不帶參數的話從這把 key 能用的模型裡選（↑↓ 移動、Enter 選、數字鍵直接選、Esc 取消）。對話中途換到別家時，之前的對話會轉成文字 |
| `/effort low…max` | 推理強度，只列出目前模型支援的 |
| `/undo` | 還原上一輪 `edit`、`write` 改過的檔案，可以連續用（`bash` 改的不能還原） |
| `/diff` | 這次用 `edit`、`write` 改了什麼 |
| `/todo` | 再看一次模型的待辦清單（做到哪裡）；只能看，要改直接跟它說 |
| `/compact` | 把之前的對話濃縮成摘要（上下文到了門檻也會自動摘要） |
| `/clear`、`/resume` | 開新的對話；接續這個資料夾之前的對話 |
| `/checks` | 改檔之後自動跑的檢查（測試、lint）；失敗的交給模型修，最多 3 次 |
| `/image <路徑>` | 附加一張圖片（也可以把圖片拖進終端機，或在問題裡打 `@路徑`） |
| `/trust`、`/add-dir` | 信任這個資料夾；這次對話多一個可讀的資料夾 |
| `/permissions` | 看設定檔裡的權限（永久允許的白名單、網域、MCP 工具）；`/permissions remove 編號` 拿掉，這次對話也馬上生效 |
| `/cost` | 這一輪、這次對話、今天、本月的花費 |
| `/tui` | 全螢幕模式（預設）和一般模式：`/tui fullscreen`、`/tui classic`（會記在設定檔，下次也用它） |
| `/language` | 介面的語言（`/language ui en`、`/language ui zh-TW`，記在設定檔）和這次對話 AI 回覆的語言（`/language reply …`） |

## 做事的時候也能打字

模型在做事的時候，輸入列照樣開著（全螢幕模式在最底下；一般模式在狀態列那一行）：

- 打好按 Enter，這句話先**排隊**（全螢幕模式畫在輸入列上面），模型做完手上這一步（下一次工具呼叫之前）就交給它；它已經講完了的話，同一輪接著回你。
  交給它的那一刻才印進對話裡，順序跟模型看到的一樣。
- 拿來補充細節、更正、喊停都可以：「第 2 項不用做了」「改用 TypeScript」「先不要動測試」。
- 這時候打的斜線指令等這一輪做完才執行（不會在模型做到一半時換模型、換對話）。
- 輸入列是空的時候按 Ctrl-C 中斷這一輪（有字的話先清掉字）。中斷時還沒交給它的話不會自動送出，會列出來，要的話再送一次。
- 你打字打到一半、剛好跳出權限詢問的話，那一下按的鍵不算回答（不然句子裡的 `y` 會被當成「是」）：停一下、看清楚再按。

## 畫面：誰在說話

每一行左邊有一欄標出是誰：

```
你 ▏請建 hello.txt

AI ▏好的，我先列計劃。
   ▏  建立 hello.txt
xj ▏▍ ── 建立 hello.txt ──
   ▏▍ 套用？  [y] 是  [n] 否  y
AI ▏    ✓ 已建立 hello.txt（+1 −0 行）
   ▏建好了。
   ▏  本輪 約 $0.01
```

- **你**：你打的字、斜線指令。**AI**：模型的回覆、它用的工具和結果、這一輪的花費。**xj**：Xing Janus 自己講的（斜線指令的回覆、權限詢問、提醒和錯誤）。
- 模型裝不出 xj 在說話：每一行最前面那 4 格一定是 Xing Janus 畫的，模型的字從第 5 格開始；那條 `▏` 跟詢問的 `▍` 一樣，模型的字、檔名、指令輸出都印不出來。

## 全螢幕模式

預設就是全螢幕模式，像 vim、htop 一樣整個畫面由 Xing Janus 畫。想用終端機自己的捲動、搜尋、選取複製，打 `/tui classic` 換成一般模式（記在設定檔的 `screen`，下次也用它），`/tui fullscreen` 換回來：

- 視窗夠寬（100 欄以上）的時候，右邊有一欄：上面是待辦清單，下面是**目前的狀態**和常用指令。不夠寬時待辦清單放在輸入列上面（最多 5 項），狀態看最底下的狀態列。
- 狀態那一段每一項前面有一個色塊，後面寫目前是什麼：模式、沙盒、信任資料夾、改檔都允許（詢問時按了 `a`）、Enter＝是、提示音、事後檢查、永久允許。
  色塊：**綠**開著、**灰**關著、**黃**開著但比較寬鬆（問得比較少）、**紅**要注意（沒有沙盒、全部不問模式）。看字就知道，色塊只是輔助（`NO_COLOR` 時沒有顏色）。
- **點一下**（同一行按下、放開）：每一項後面的灰字寫點了會做什麼（切換、收回、列出）；點了不會切換的（沙盒、信任資料夾、關著的改檔都允許），下一行寫怎麼改。提示音、Enter＝是切換開／關（只在這次對話）；模式換下一個（跟 Shift-Tab 一樣）；
  改檔都允許開著的時候點一下就收回（關著的點了不會打開：要在改檔的詢問時按 `a`）；信任資料夾、沙盒只講怎麼改，不會切換；
  事後檢查、永久允許列出內容；常用指令填進輸入列（看過再按 Enter）。點了之後最下面那一行講改了什麼。貼上的內容裡夾著的滑鼠控制碼不算點擊。
- 捲動：PageUp／PageDown、滑鼠滾輪。往上捲的時候新的輸出不會把畫面拉下去（最底下會講還有幾行沒看）；送出新的訊息就回到最底下。
- **選取、複製**：在對話那一欄拖曳就反白，放開就複製到剪貼簿（只選對話的字，不含左邊的標籤和右邊那一欄；被折下來的長句接回一行）。點一下或按任何鍵，反白就收掉。
  反白還在的時候按 Ctrl-C 是複製、不會中斷（跟 Windows Terminal 一樣：有選取時 Ctrl-C 是複製，沒有才是中斷）；這一輪還在跑的話，狀態列會講「要中斷這一輪，再按一次 Ctrl-C」。
  在 SSH 連線裡、或 Linux 沒有 wl-copy／xclip 時，交給終端機（OSC 52：iTerm2、tmux、Windows Terminal 支援，Terminal.app 不支援）。
  想用終端機自己的選取：iTerm2 按住 Option 拖曳，或打 `/tui classic` 換成一般模式。
- 終端機自己的搜尋（Cmd+F）找不到全螢幕裡的對話。離開全螢幕（`/tui classic`、離開 xj）時，整段對話會印回一般的畫面，之後就找得到了。
- 輸出不是終端機、`TERM=dumb`、視窗太小、舊的 Windows 主控台時開不了，照舊用一般模式。

## 不互動的模式（給腳本用）

```bash
xj -p "這個專案的測試指令是什麼？"
git diff | xj -p "幫這段改動寫一行 commit 訊息"
```

回覆印到 stdout，工具動作和花費印到 stderr。要問你的動作（改檔、不在白名單的指令、新的網域）一律拒絕；沒問過信任的資料夾當成不信任。

從管線傳進來的內容是資料，不是你打的問題：裡面的 `@路徑` 不會附加檔案。要附加，寫在 `-p` 的問題裡（`git diff | xj -p "對照 @docs/style.md 檢查這段改動"`）。

## 狀態列

最底下一行：模型 · effort · 模式 · 沙盒 · 上下文（用了多少／摘要的門檻） · 待辦（有還沒做完的待辦清單時，例如「待辦 2/5：正在寫測試」） · 今天的花費 · 本月的花費（跟上限比）。工作中顯示最新的進度。視窗太窄時從最後面開始省略。沒有沙盒時整列標紅。
要哪些欄位、什麼順序，寫在設定檔的 `statusBar.fields`。

上下文那一欄後面有 **`?`** 的話，表示查不到這個模型的能力，用的是保守的預設值（上下文 32k、輸出 8k）——
自訂的服務常常這樣。真實的值可以寫進設定檔的 `capabilities`（見 [config.md](config.md)），不然你會只用到模型的一部分。

## 待辦清單

做多步驟的工作（改一個功能、修一串測試、你一次交代好幾件事）時，模型會先列一張待辦清單，做一項標一項：

```
  更新待辦清單
    ✓ 讀現有的程式
    ► 寫測試
    ☐ 實作
```

- 每次更新都印出整張（全螢幕模式畫在右邊或輸入列上面，不印進對話裡）；狀態列顯示做到第幾項、正在做什麼。`/todo` 隨時再看一次。
- 清單只列你這次交代的那件工作。做完了狀態列的待辦就不見；再交代新的工作，換成新的一張（不會越積越多）。
- 你不用管這張清單，直接跟它說就好（它在做事的時候也可以說，見下面的「做事的時候也能打字」）：多交代的事它會加進清單（之前做完的留著）；
  說「第 3 項不用做了」「README 那一項改成英文」，它會找出是哪一項、改掉或刪掉。清單有編號，畫面上的編號跟它看到的一樣。
- 清單不碰檔案、不跑程式，所以不會問你（唯讀、計劃模式也能用）。
- 清單只存在這台電腦（xj 的記憶體和 `~/.xing-janus/sessions/` 的對話紀錄，給 `/resume` 用），沒有另外送到別的服務；清單是模型寫的，本來就是跟模型的對話的一部分。
- 摘要之後、`/resume` 接續時清單還在（摘要之後也會再給模型看一次，免得它忘了還剩什麼）；`/clear` 開新的對話就清空。
- 一步就做完的事、單純的問答，模型不會列清單。每個模型都有這個工具；不想讓某個模型用，在設定檔的 `capabilities` 寫 `"todoTool": false`（例如 `"anthropic:claude-opus-5-5": { "todoTool": false }`）。

## 抓網頁

模型可以抓一個網址來看（查套件的文件、changelog、GitHub 上的 issue），工具叫 `web_fetch`：

- 只用 GET，不帶 cookie、不帶你的任何登入資訊。只收文字（HTML 轉成純文字，標題、清單、程式碼、連結留著，script、style 拿掉）；
  圖片、PDF 不收。一頁最多下載 5 MB、30 秒；給模型的最多 4 萬字，太長的它會接著往下讀。同一個網址 15 分鐘內再抓用上次的結果。
- **網域要問**，跟沙盒的網域同一份清單（見上面的「權限詢問」）；問的時候整個網址看得到。永久允許寫進 `sandbox.allowedDomains`。
- **網址裡有看起來像金鑰的字**：允許過的網域也問，而且只能允許這一次（網址會送到那個網站，它看得到）。
  換個寫法也算：前面多接一個字、百分比編碼（`%2D`）、放在路徑裡。編碼成 base64 之類的看不出來，所以允許過的網域照樣要你自己判斷（見 cerberus.md）。
- **不問就擋**：本機（`localhost`、`127.0.0.1`）、直接寫成內網位址的（`10.x`、`192.168.x`…）、雲端的 metadata 位址、帶帳號密碼的網址（`user:pass@`）、
  藏在 IPv6 寫法裡的這些位址（NAT64、6to4）、這台機器自己的位址、連接埠 0；
  名稱解析到本機、metadata 的也擋（連線用的就是檢查過的那個位址）。名稱解析到內網的照樣問你，不直接擋（公司或組織內部的文件網站才用得了）。
  要抓本機的開發伺服器，在設定檔的 `sandbox.allowedDomains` 寫明（例如 `127.0.0.1:3000`）。
- **轉址**：同一個網站的照跟（最多 5 次）；轉到別的網站的不跟，把新網址告訴模型，它要抓的話是新的網域，會再問你。
- 抓到的內容給模型時標明是網頁的內容（資料，不是指令，見 [cerberus.md](cerberus.md) 的「提示注入」）；畫面上只印抓了多少字，不印內容。
- 唯讀、計劃模式、不信任的資料夾也能用（只是讀，網域照樣問）。全自動模式照樣問網域；全部不問模式不問網域，但上面「不問就擋」的照樣擋。
  不互動的模式（`xj -p`）沒允許過的網域一律拒絕。
- 沒有搜尋：要它查的話，給它網址，或讓它自己找文件的網址。
- 不想讓某個模型用：設定檔的 `capabilities` 寫 `"webFetch": false`。

## 子代理

模型可以把一件事交給子代理去做：子代理在自己的上下文裡讀檔、搜尋、改檔，做完只把報告交回來，主對話不會被它讀的一大堆檔案塞滿；
幾件獨立的調查可以同時跑。

- 每個模型都有這個工具。它通常自己做，你要它分頭去查、交給子代理改的時候直接講（「用兩個子代理同時查 A 和 B」）。
  不想讓某個模型用：設定檔的 `capabilities` 寫 `"subagents": false`（例如 `"anthropic:claude-opus-5-5": { "subagents": false }`）。
- **兩種**：`explore` 找東西、讀程式，**一定是唯讀**，最多同時 4 個；`general` 會改檔、跑指令，一次一個。
- **權限跟主對話一樣**：子代理的每個動作都經過 Cerberus（同一套權限、沙盒、機密檔、允許過的網域），不比主對話寬：
  - `explore`：主對話是全自動、全部不問也照樣是唯讀。
  - `general`：照主對話的模式（一般模式改檔照樣秀 diff 問你）；唯讀、計劃模式、不信任的資料夾開不了。
  - 要問的時候，詢問的第一行寫是哪個子代理（「子代理「改 README」：修改 README.md」）。**答應的是你**，主代理不能替你答應。
    沙盒裡的指令（例如 curl）要連新網域時是例外：那是沙盒的代理程式問的，只知道要連哪裡，看不出是哪個子代理的指令。
  - 好幾個詢問接連跳出來（同時跑的子代理）：下一個剛跳出來的半秒內按的鍵不算，連按兩下不會答到下一題。
- **畫面**：一個子代理一行。全螢幕模式跑的時候那一行會更新（做了幾個動作、改了幾次、花多少），做完換成結果；一般模式開始、做完各印一行。
  全螢幕模式的寬視窗右邊那一欄，待辦清單下面列出這一輪的子代理（幾個在跑、各做到哪裡），這一輪結束就收掉。
  子代理的每個動作不一一印出來（要問你的照常跳出來）。
- **改了什麼由 xj 算**：`general` 做完，交給主代理的除了報告，還有 xj 自己算的「改了哪些檔、各加減幾行」（不是子代理說的），
  主代理被交代回覆你之前要看過這些改動、跑過測試。`/undo` 照樣還原整輪（子代理用 edit、write 改的也算），事後檢查照樣跑。
- **模型**：預設跟主對話同一個。要換的話直接講（「用 Haiku 去找」），或在設定檔寫 `subagents.model`（寫法跟 `/model` 一樣，例如 `anthropic:haiku`）。
  用的不是主對話的模型時，那一行會標出來。模型自己要換到別家的模型時會先問你（交代的內容和它讀到的東西會送到那一家），
  設定檔的 `subagents.model` 是你自己設的，不問。主對話沒給的工具（例如能力表關掉的 `web_fetch`），換了模型也拿不到。
- **上限**：每個子代理最多 30 個工具呼叫、10 分鐘，到了就叫它把找到的交回來。花費算進這一輪，每輪的預算照樣有效；
  它做的動作也算進每輪的工具呼叫上限（到了照樣停下來問你）。
  都可以在設定檔的 `subagents` 改（見 [config.md](config.md)）。
- 子代理不能再開子代理，也不能用待辦清單、MCP、技能。完整的過程存在對話紀錄旁邊的 `subagents/`（`/resume` 只接主對話）。

## 花費和預算

畫面上的金額都標「約」：那是**預估**（本機價格表 × 用量），不是帳單 —— 服務商會調價，實際金額以他們的帳單為準。

每一輪、每天、每月都有上限（設定檔的 `budget`，預設每輪 $5、每天 $30、每月 $100；填 0 等於關掉那一項），到 80% 提醒、到 100% 停下來問你。`xj setup` 不會問你預算，要改就改設定檔。價格表在 `~/.xing-janus/prices.json`，每一筆都寫了來源和日期；超過三個月沒更新，`xj doctor` 會提醒。本地模型（Ollama）算 $0。服務沒有回報用了多少 token 的請求，花費顯示「未知」（不會當成 $0），一輪裡累積太多個會停下來問你。

## 專案規則、技能、MCP

- **AGENTS.md**（有 CLAUDE.md 也讀）：寫給 coding agent 的規矩，例如測試指令、程式風格。只在信任的資料夾讀。
- **技能**：`~/.xing-janus/skills/<名稱>/SKILL.md`，或專案裡的 `.agents/skills/`。平常只把名稱和說明告訴模型，用到才讀內容。
- **MCP server**：只接設定檔列出的，預設在沙盒裡跑，每次呼叫都會問（設定檔的 `autoApprove` 列的除外）。

## Flutter 專案

不用另外設定。沙盒開著時 `flutter`、`dart` 在沙盒裡跑不了：模型會要求在沙盒外跑那一個指令、每次問你（config.md「沙盒裡跑不了的工具」），用的是你自己的環境（`JAVA_HOME`、`ANDROID_HOME` 預設就帶過去）；沙盒也因此不再開放 Flutter SDK、Pub cache，開得比較快。沒有沙盒時照一般的規則。

## 語言

介面（xj 印的每一句）有英文和繁體中文。第一次啟動時會問要哪一種（預設是系統的語言），記在設定檔的 `uiLanguage`；之後隨時用 `/language ui en`、`/language ui zh-TW` 換。
給模型的說明和工具結果一律是英文；AI 用什麼語言回你是另一個設定：設定檔的 `language`（預設跟介面一樣），或 `/language reply <語言>` 只改這次對話。
